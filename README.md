# ReApple — демо маркетплейса

Кликабельное демо маркетплейса б/у и новой техники Apple: сделано за вечер, чтобы обсудить продукт и ТЗ с заказчиком до разработки. Не MVP: без бэкенда, оплата, доставка и проверка IMEI понарошку. Название и продавцы вымышленные.

**Посмотреть:** https://vshgit.github.io/reapple/

- `index.html` — витрина, кабинет продавца и бэк-офис в одной странице; данные лотов встроены, состояние хранится в браузере.
- `ph/` — фото лотов (по 6 кадров на лот в одном файле).
- `ref/` — эталонные фото моделей с сайта Apple, только для демо.

Сверху переключатель ролей и кнопка «Сценарий» со сквозной цепочкой из 6 шагов.
